# 股票操作复盘

先调用 `get_stock_review` 读取所选账户、周期、市场和基准币种的确定性报告；股票或 Campaign 请求传 `symbol` / `campaign_id`。报告中的数值、状态、问题和事实标签是唯一计算来源。指标为 `unavailable`、`degraded` 或 `pending` 时照实解释，不重算、不补零。

## 回答契约

按以下顺序输出，且分别标明确定性事实与状态、基于数据的推断、用户背景、待确认问题：

1. 一句话结论
2. 确定性事实
3. 做得较好
4. 值得复盘
5. 无法仅凭数据判断
6. 下一周期建议

事实先讲结果质量和调仓增益，再讲 60/120 交易日后续效果、风险结构和主要归因。历史手工评价只能作为用户背景，不能覆盖确定性结果。

## 追问策略

只为下列候选问题追问：单项贡献绝对值超过本期调仓增益或损失的 20%；单股权重变化绝对值超过 5 个百分点；结果与风险结论冲突；歧义会改变指标；答案可形成目标仓位、持有周期、投资逻辑等长期复用背景。按影响排序，最多三个，并明确用户可以跳过。

已回答、报告可确定、低影响或只为补全文字的问题不问。没有符合条件的问题就直接完成复盘。

## 写入边界

用户明确要求保存/记录背景时，先形成结构化草稿并等待宿主对该草稿的可信确认；只有宿主提供与草稿精确绑定的一次性确认能力后才调用 `save_stock_review_annotation`。聊天文字或工具参数不能授权写入；收到 `confirmation_required` 时不重试、不声称已保存。该工具只保存注释，不纠正或覆盖交易与指标。

## 禁止项

- 不输出综合分或自动“正确/错误”标签。
- 不把相关性或事后结果写成因果结论。
- 不提供报价、短期预测或具体买卖建议。
- 不自行计算 TWR、影子收益、调仓增益、60/120 日效果、Campaign 盈亏或任何替代指标。
