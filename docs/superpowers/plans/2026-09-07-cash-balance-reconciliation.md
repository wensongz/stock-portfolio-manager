## 验证结果（2026-09-07）

- `bun run check` 通过：前端 299 项通过；Rust 727 项通过、13 项忽略；构建、Rust 格式和 Clippy 检查通过。构建保留既有分包体积提示。
- 后端覆盖推荐采用不改交易、自定义期初差额、后续交易增删改、零与负数、UTC 排序、并发读取一致性、旧版本拒绝及原子回滚。
- 浏览器使用仅含合成账户的临时页面验证：推荐只填入草稿；确认后余额即时刷新；缓存的旧行情不会覆盖余额；明细推荐与最终余额一致，支出显示负号。临时页面和服务已关闭。
- 日度与季度回归覆盖期初生效日前为零、跨季度生效和负余额。
