# P0 季度快照数据完整性设计

## 背景

历史季度的“创建”和“刷新”当前使用两套实现。创建路径读取今天仍然存在且数量大于零的 `holdings`，缺少历史价格时会退回实时行情，最终还会把未解析出的价格写成零。刷新路径则尝试从交易流水重放历史持仓，但只更新已有明细，依赖今天的 `holdings` 补充元数据，并会忽略历史行情请求错误。因此，同一个季度通过不同入口可能得到不同的持仓、价格和总额。

## 目标

- 创建和刷新共用唯一的季度快照重建流程。
- 历史季度以季度末为界，从交易流水还原每个账户的证券持仓和成本。
- 历史季度只接受季度末当日或之前的有效收盘价；当前季度才允许实时行情。
- 任何必需价格或汇率缺失时，不写入快照，不保留部分更新，也不以零代替。
- 重建时保留季度总评和账户级持仓备注。
- 同一账户和股票的创建结果与刷新结果一致；同一股票跨账户保持独立明细。

## 非目标

- 不改变交易成本计算开关的产品语义。
- 不引入数据库迁移或新的持久化表。
- 不改变季度比较、笔记历史和前端交互协议。
- 不为历史数据发明汇率；历史跨币种估值必须使用已保存的日度汇率。

## 设计

### 单一重建入口

新增 `quarterly/rebuild.rs`，由 `create_quarterly_snapshot` 和 `refresh_quarterly_snapshot` 调用同一个 `rebuild_quarterly_snapshot`。入口接收目标季度和可选的既有快照 ID，依次完成：确定估值日、加载或重放持仓、解析价格、解析汇率、计算明细和汇总、在一个 SQLite 事务中替换快照。

创建已存在季度时复用既有快照 ID、`created_at`、`overall_notes` 和持仓备注；首次创建使用新 ID。刷新只负责通过 ID 找到季度，然后调用相同重建入口。

### 持仓来源

当前季度以 `holdings` 为权威来源，保留数量大于零的持仓。

历史季度查询估值日及之前的非现金交易，按 `(account_id, UPPER(symbol), market)` 分组，并按 `traded_at, created_at` 顺序重放 `OPEN/BUY/SELL/PAY`。名称和市场优先来自交易本身；账户名称来自 `accounts`；类别优先来自仍存在的持仓，否则使用“未分类”。重放结果数量不大于零的组合不进入快照。

成本重放继续遵守 `quote_provider_config` 中各市场的 SELL/PAY 成本调整开关。未知交易类型、非有限数值或卖出后形成负持仓属于数据错误，整个重建失败。

现金不在本轮从证券交易反推。现有季度分析的核心是证券持仓，历史现金缺少可靠的起始余额来源；与其推导不完整现金，不在历史快照中制造它。当前季度沿用现有实时持仓行为。

### 价格来源

价格键使用 `(UPPER(symbol), market)`，避免不同市场同代码互相污染。

- 现金持仓固定价格为 `1.0`。
- 历史季度先读取 `daily_holding_snapshots` 中估值日或之前的最近有效价格；缺失时向配置的行情源请求估值日前十天至后两天的历史数据，并只选择估值日或之前的最后一个有效收盘价。
- 当前季度批量读取实时/缓存行情。

只要任一证券缺少大于零且有限的价格，就返回包含账户、市场和代码的错误。历史路径不得调用实时行情作为后备。

### 汇率来源

当前季度使用 `get_cached_rates`；该函数自身已经按“新鲜内存缓存、网络、陈旧内存缓存、持久化缓存”的顺序降级。

历史季度读取 `daily_portfolio_values` 中估值日或之前最近一条 `exchange_rates`，反序列化并验证三个汇率均为有限正数。不存在或格式无效时失败。不会使用当前汇率或硬编码常数冒充历史汇率。

### 原子写入与备注

所有价格、汇率和计算必须在开启写事务之前成功。写事务先删除目标快照的全部持仓明细，再插入完整的新明细，最后 UPSERT 快照头并提交。任何 SQL 错误导致事务回滚。

持仓备注按 `(account_id, UPPER(symbol))` 保存，防止同一股票跨账户串备注。季度总评和原 `created_at` 保持不变。

## 错误语义

- “没有任何可快照的持仓”返回明确业务错误。
- 行情源请求失败可以继续检查其他证券，但最终只要仍有缺价就整体失败。
- SQL、字段解码、历史汇率反序列化和日期解析错误向上传播。
- 已存在快照在任何失败后保持字节层面的业务状态不变。

## 验证

回归测试至少覆盖：季度前买入、季度内加仓/卖出、季度末前清仓、季度末后卖出、多账户同代码、创建后刷新结果一致、备注按账户保留、缺少价格不产生部分快照、缺少历史汇率不产生部分快照，以及注入写入错误时事务回滚。
