# 季度快照账户操作历史修复

## 问题和目标

快照子表的“历史”只传入证券代码，读取所有账户、所有季度的快照笔记，未读取用户期望的本季度操作流水。同一弹窗保存笔记也仅按快照和代码更新，可能覆盖其他账户。

历史查询改为使用所点快照持仓行的唯一 ID 与快照 ID。后端从该行解析账户、证券、市场和币种，限定当前季度的完整日期范围。股票展示对应证券操作；现金展示该账户该币种的资金变动，复用现金回放规则并保留季度开始前的余额基线。日期边界使用已有季度计算的 UTC 口径。

保存思考只更新所点快照持仓行；历史不会再返回跨季度快照笔记。不存在的行、错误快照归属和加载失败均明确反馈。

## 验证结果

- 新增后端回归 7 项，覆盖三个账户、Q1/Q3、证券市场和币种、季度边界、现金余额基线、空记录、错误归属及笔记精确保存；先复现失败再修复。
- 前端覆盖精确请求参数、迟到响应隔离、失败重试与草稿保留、单行笔记保存、重建后的无效目标和 UTC/金额展示。
- 合成数据界面实际验证：现金只显示所点账户的 Q1 变动；无操作账户显示空记录；股票只显示该账户的当季操作；季度末 UTC 时间保持在正确季度。临时页面及服务已关闭。
- `bun run check` 通过：前端 307 项通过，Rust 734 项通过、13 项忽略；构建、格式和 Clippy 检查通过。构建保留既有分包体积提示。
- 独立复核确认笔记保存和重建按账户隔离，未扩大修复历史混币种异常数据的范围。
