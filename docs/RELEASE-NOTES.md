# v1.6.0 Release Notes

> 主要变化范围：v1.4.0 → v1.6.0

## 🌟 重点更新

### 📈 股票操作复盘
- 新增轻量化股票操作复盘：可按账户、时间范围、市场和本位币查看买入、加仓、减仓与清仓操作
- 基于原始交易记录合并连续操作，并按标的汇总正向/负向价格效果、估算权重变化等关键事实
- 引入相对“不执行该笔操作”的期末价格效果，以及按买卖方向调整的市场宽基超额收益，便于区分绝对表现和相对表现
- 明确展示行情、汇率、基准和估算权重等数据缺口；单个字段缺失不会阻断整份报告
- 支持一键交给 AI 助手继续复盘；AI 仅做只读分析，不修改交易或确定性指标，也不自动给操作打“正确/错误”分

### 📝 期权操作复盘
- 新增期权复盘 Tab，按每笔卖出开仓建立 Campaign，并匹配后续买回平仓记录
- 按标的和 Campaign 展示净权利金、留存率、担保名义资本口径年化收益率、最差 Campaign 与数据质量标签
- 完善部分平仓、多次平仓、拆股调整、跨时间记录和未匹配记录等复杂场景的处理
- 记住上次选择的账户和复盘周期，并可将确定性报告一键发送到 AI 助手继续分析
- 优化已到期期权汇总：按标的展示净权利金、指派/到期数量、指派率及单条平均净权利金；已完成记录按到期日倒序排列

### 💰 分红分析
- 新增分红分析页面，可按年份汇总美股、A 股和港股的分红/利息收入
- 支持按市场、账户和标的交叉查看明细，并将各市场本位币金额换算为所选汇总币种
- IBKR 交易导入新增现金分红记录识别，同时兼容逗号分隔和制表符分隔文件

## 🤖 AI 助手
- 新增 Anthropic Claude 官方 API 支持，包括消息协议、流式回复、推理内容与工具调用
- 股票和期权复盘均可携带当前筛选条件及确定性数据进入 AI 助手，减少重复配置
- 记住 AI 会话侧边栏的展开/收起状态，并加强预填内容、会话切换和工具调用状态的一致性
- 更新内置复盘技能与工具说明，进一步区分确定性事实、数据推断和待补充的投资背景

## 📊 统计、绩效与数据质量
- 统计分析的整体、市场和类别视图新增或统一账户级持仓明细，可继续下钻查看单账户交易记录
- 季度快照按“市场 + 标的”聚合同一证券，避免多账户持仓在季度对比中重复展示
- 修正绩效收益、风险指标、现金流边界和历史快照补齐逻辑，提高收益曲线与汇总卡片的一致性
- 行情与快照计算加强交易日覆盖校验；雪球行情失败会在界面显示具体错误，同时保留可用缓存
- 拒绝无效持仓平均成本，降低异常数据进入后续统计和绩效分析的风险

## 🎨 使用体验
- 投资类别管理移入设置页，集中管理通用设置、类别、备份、期权和 AI 配置
- 统一持仓、交易、统计、绩效、分红和复盘页面的表格密度、列宽、汇总卡片及操作按钮布局
- 持仓和交易表格会记住分页大小；期权复盘会记住上次选择的账户与周期
- 页面标题图标增加统一配色，盈亏颜色设置在统计明细中保持一致
- README 重写为中英双语版本，补充数据存储、行情源、AI 提供商、测试与构建说明

## 🔧 构建与稳定性
- CI 和本地 Tauri 构建流程改用 Bun 安装依赖及构建前端
- 为股票/期权复盘、分页偏好、行情错误、季度聚合和 AI 预填等关键路径补充自动化测试
- 清理旧版股票复盘引擎和重复界面，最终版本保留更易解释、只读且数据边界明确的复盘流程

# v1.4.0 Release Notes

> 主要变化范围：v1.2.2 → v1.4.0

## ✨ 新功能

### 🤖 AI 智能助手（新增）
- 全新对话式 AI 助手：多会话管理、流式对话、会话持久化
- 支持多模型提供商，动态获取模型列表
- Markdown 技能系统：内置技能 + 自动/手动触发激活
- 内置数据工具：持仓查询、交易记录、期权持仓等函数调用
- 推理过程与工具调用卡片展示、代码高亮
- 新增 6 个投资分析技能（技术指标、基本面分析等）
- 新增「芒格视角」技能：用芒格的思维框架分析公司与投资组合（触发词：芒格视角 / 芒格）

### 💰 现金存取
- 交易记录支持「存入现金 / 提取现金」操作（复用 `$CASH-*` 现金持仓机制）
- 提取现金超额校验（不能超过现金余额）

### 🎨 主题与设置
- 深色 / 浅色 / 跟随系统 主题支持（CSS 变量）
- 设置页新增「恢复出厂设置」：清空全部数据并还原默认

## 🚀 行情数据
- 新增东方财富（East Money）作为美股行情的免登录主数据源，带提供商回退链
- 雪球：一键登录 + Cookie 粘贴流程（修复登录窗口关闭竞态问题）
- 修复指数行情获取

## 📊 统计分析
- 整体统计 Tab 新增「个股明细」表格
- 修复：已清仓股票的盈亏计算（此前漏算 OPEN 建仓成本，导致清仓后显示盈利）
- 修复：个股明细排除已清仓股票（与市场统计口径一致）
- 总盈亏前移除货币符号，+/- 不再出现在货币符号后
- 显示行情数据更新时间；汇率卡片新增 HKD/CNY 汇率显示

## 📝 期权管理
- 导入 CSV 支持英文（IBKR 风格）字段名，表头匹配大小写不敏感
- 导入边界检测：平仓记录找不到对应开仓记录时拒绝插入，避免数据不一致
- 修复：纯 `C` 代码（买回平仓）未被识别为平仓，导致已平仓合约仍显示 active
- 修复：导出→清除→重新导入后开仓匹配失败（导出负数量的绝对值处理）

## 🗂 持仓 / 交易记录
- 持仓管理和交易记录记住上次「按账户」的选择（重启后自动恢复）

## 🔧 其他
- 窗口默认不再最大化启动
- 全量升级前后端依赖至最新版本；锁定 Rust 1.97.1、要求 Node ≥ 26
