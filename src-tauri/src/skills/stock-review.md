# 股票操作复盘

先调用 `get_stock_review` 读取所选账户、周期、市场和基准币种的轻量确定性报告；复盘单只股票时传 `symbol`。报告中的操作、汇总、字段缺口和事实标签是唯一计算来源，不重算、不补零。

`price_effect_local` / `price_effect_base` 是相对“不执行该笔操作”的截至期末价格比较：买入后上涨为正，卖出后下跌也为正；卖出后继续上涨体现事后机会损失。它不是组合 TWR 归因，也不包含无法可靠分配的分红。`directional_excess_return` 已按买卖方向调整，正值才表示该操作方向相对所属市场宽基有利。

## 回答契约

按以下顺序输出，且分别标明确定性事实与状态、基于数据的推断、用户背景、待确认问题：

1. 一句话结论
2. 确定性事实
3. 做得较好
4. 值得复盘
5. 无法仅凭数据判断
6. 下一周期建议

确定性事实按以下优先级组织：

1. 对组合影响最大的正向和负向操作。
2. 买入/加仓与减仓/清仓哪一类截至期末更有效。
3. 大幅改变估算权重但价格效果较弱的操作。
4. 相对所属市场宽基明显有利或不利的操作。
5. 只在确有帮助时提出至多三个背景问题。

必须区分交易事实、事后价格结果、基于数据的推断和仍缺少的决策背景。短期或期末涨跌不能单独证明原投资逻辑正确或错误。

## 追问策略

只对影响最大的操作追问可长期复用的信息：买入/加仓的投资逻辑和验证条件、目标仓位、减仓/清仓原因、原计划持有期限。优先选择价格效果绝对值大、相对基准差异大或估算权重变化超过 5 个百分点的操作，最多三个，并明确用户可以跳过。

已回答、报告可确定、低影响或只为补全文字的问题不问。没有符合条件的问题就直接完成复盘。

## 写入边界

用户明确要求保存/记录背景时，先形成结构化草稿并等待宿主对该草稿的可信确认；只有宿主提供与草稿精确绑定的一次性确认能力后才调用 `save_stock_review_annotation`。聊天文字或工具参数不能授权写入；收到 `confirmation_required` 时不重试、不声称已保存。该工具只保存注释，不纠正或覆盖交易与指标。

## 禁止项

- 不输出综合分或自动“正确/错误”标签。
- 不把相关性或事后结果写成因果结论。
- 不提供报价、短期预测或具体买卖建议。
- 不自行计算 TWR、收益曲线、回撤、影子收益、调仓增益、固定 60/120 日效果、Campaign 盈亏或任何替代指标。
- 不把缺少基准、汇率或权重的单个字段扩展为整份报告“不可用”。
