# 季度快照缺失现金恢复

## 已确认情况

只读核对发现旧 Q2 快照仅保存一条现金行，相关账户、币种的资金流水仍然存在。现有历史快照重建会重新加载全部现金，而不是只刷新旧快照已经包含的现金行；合成多账户场景验证了这一点。

另有两个实际缺口：有入金流水但当前现金持仓已不存在时，无现金 OPEN 会导致恢复失败；刷新失败时详情页未显示错误，旧缺行快照会继续留在页面上。

## 修复范围

- [x] 增加旧快照缺现金后的真实刷新回归，验证账户及币种隔离、季度末余额、零和负数、重复刷新、总额及原笔记和历史汇率。
- [x] 无当前现金持仓、无 OPEN，但季度末之前存在明确现金入金时，允许依据完整资金流水恢复现金。保留已有期初和旧现金基线规则，不对仅有股票流水且无基线的账户推测余额。
- [x] 页面明确显示读取或刷新失败，保留旧数据时说明显示状态并允许重试；成功后立即展示返回的新现金行和总额。
- [x] 合成数据界面验证、独立复核及完整检查。
