# 导入批次与对账

股票持仓和交易的券商 CSV、通用 CSV、截图 OCR 导入都会先建立可持久保存的批次。期权仍使用原来的独立导入流程。

## 导入

1. 从持仓、交易或导入导出页面上传文件；在原有预览中修正数据。
2. 点击检查，查看后端批次预览。待导入行默认选中，疑似重复行默认不选。
3. 核查后点击“导入所选行”。明确重复和已导入行不会再次写入。
4. 部分失败时，成功行保留；可以只选失败行重试。格式错误需要从原文件修正后新建批次，不能在历史中改写审计原文。

“明确重复”包括同一来源的成交编号，以及相同原始文件中的相同导入行。相同文件行或成交编号的内容发生冲突时拒绝写入。缺少成交编号但业务字段相同，仅标记“疑似重复”；确认为另一笔合法成交时可勾选导入。提交时仍会重新查重；新出现的疑似重复需要重新勾选。

旧版导入和手工交易没有来源编号，只能按业务字段提示疑似重复。不要把提示当成绝对的重复判定。

## 历史与恢复

在“导入导出”页面底部的“导入批次历史”查看最近 100 个批次，重启应用后仍可查看、重试、核对和撤销。每个批次保存原始内容、来源、文件名、解析版本、标准化数据及逐行结果。

撤销恢复该账户第一次提交前的持仓、现金和交易，其他账户保持原状。如果该账户在批次最后一次提交后有新增/编辑/删除交易或持仓等变更，会拒绝撤销和重试。多个批次可按相反顺序撤销。失败撤销会整体回滚，不留下半撤销状态。已撤销批次保留历史，但不能再次提交；需要重新上传建立新批次。

## 对账

表格展示批次首次提交前、最后一次提交后的证券数量与现金余额。它是批次快照，不是实时行情或当前账户余额。

填写券商对应时点的持仓数量、现金余额，保存后查看差额。没有填写的项目显示“未核对”，不会显示全部对账成功。也可添加券商有、应用没有的证券代码，检查漏记持仓。现金代码为 `$CASH-USD`、`$CASH-CNY`、`$CASH-HKD`。

成功导入或撤销后，受影响日期起的每日估值快照失效，进入绩效页面会重新补齐。季度快照与投资笔记保留，历史数据调整后请按需刷新相应季度。
